# Version 1.1.0 — Release Notes

## English

**What's New**

- **RSI Indicator** — View the Relative Strength Index for each stock directly in the details screen
- **Stock History Charts** — Beautiful line charts showing price trends with gradient fills and blurred backgrounds
- **Bottom Sheet Details** — Tap any stock to see its full details in a native bottom sheet with action buttons
- **Quick Alert Creation** — Create price alerts directly from the stock details sheet
- **New Transaction Sheet** — Add buy/sell transactions inline without leaving the portfolio screen
- **Target Price Sheet** — Set and track target prices for your holdings with projected returns
- **Database Migration System** — Future updates will apply schema changes automatically — no more reinstalls
- **Improved Portfolio Cards** — New design with performance gauge bars and clearer target gain tracking
- **Unified Dashboard** — Android dashboard now matches the iOS experience
- **Android 16 Support** — Updated to target Android 16 (API level 36)

**Fixes & Improvements**
- Fixed keyboard handling in bottom sheets with text inputs
- Safe area support for floating action buttons
- Cleaner alerts screen with bottom sheet form
- Various UI refinements and performance improvements

## Français

**Nouveautés**

- **Indicateur RSI** — Consultez le Relative Strength Index pour chaque action directement dans l'écran de détails
- **Graphiques d'historique** — De magnifiques courbes de prix avec dégradés et arrière-plans floutés
- **Fiche détail en bottom sheet** — Appuyez sur une action pour voir tous ses détails dans une feuille native avec boutons d'action
- **Création rapide d'alertes** — Créez des alertes de prix directement depuis la fiche détail
- **Nouvelle feuille de transaction** — Ajoutez des transactions d'achat/vente sans quitter l'écran du portefeuille
- **Feuille de prix cible** — Définissez et suivez les prix cibles pour vos positions avec rendements projetés
- **Système de migration de base de données** — Les futures mises à jour appliqueront les changements de schéma automatiquement — plus besoin de réinstaller
- **Cartes de portefeuille améliorées** — Nouveau design avec barres de progression et suivi plus clair des gains cibles
- **Tableau de bord unifié** — Le tableau de bord Android correspond désormais à l'expérience iOS
- **Support Android 16** — Mise à jour pour cibler Android 16 (API niveau 36)

**Correctifs et améliorations**
- Correction de la gestion du clavier dans les bottom sheets avec champs de saisie
- Support des zones sécurisées pour les boutons d'action flottants
- Écran d'alertes plus propre avec formulaire en bottom sheet
- Diverses améliorations de l'interface et des performances
